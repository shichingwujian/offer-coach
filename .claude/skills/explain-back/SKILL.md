# explain-back：讲解验收

简历项目的真正考场是面试。这个 skill 保证是用户学会了，不是 AI 学会了。

## 触发

一个阶段（如 Query Engine、知识库、Tools）的功能完成且测试全过之后。

## 流程

1. 请用户**不看代码**，用大白话讲：这一阶段做了什么、数据怎么流、为什么这么设计。
2. AI 根据用户讲解出 3 个"为什么"问题，难度递进，例如：
   - 为什么这样设计？（设计动机）
   - 不用 X 会怎样？（取舍理解）
   - 这里出错了系统怎么表现、你怎么发现？（故障意识）
3. 评判：
   - **通过**：用户能答出核心点（不要求术语精确，要求因果正确）→ 把讲解整理成 `learning/<阶段名>.md`，含一张架构示意图（mermaid 或 ASCII）+ 三个为什么的问答记录。
   - **不通过**：AI 用大白话重讲薄弱点，换个角度再问一次。仍不通过则记入 progress.md "阻塞/问题"，禁止进入下一阶段。
4. 关键结论同步进 decisions.md。
