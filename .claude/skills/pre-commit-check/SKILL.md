# pre-commit-check：提交前检查

## 触发

用户说"提交"、"完成"、"收尾"，或 AI 判断一个任务即将闭环时。

## 流程

1. `pytest` —— 必须全过。有失败：报告失败用例，修完再回来，禁止跳过。
2. `git diff --check`（有暂存改动时也对 staged 查）—— 无空白错误。
3. `git status` —— 检查没有 `.env`、`*.db`、`__pycache__` 混入待提交。
4. 检查 progress.md 是否已更新（当前任务移到"已完成"，首行"下次从这里开始"已改写）。
5. 全部通过后，向用户汇报：测试结果、改了哪些文件、建议的提交信息。
6. **是否提交由用户决定**；禁止 `git push`。
